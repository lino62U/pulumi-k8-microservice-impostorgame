# Frontend

This is a React-based frontend application for Impostor Game

## Commands
1. Install `pnpm` if you haven't already:

  ```bash
  curl -fsSL https://get.pnpm.io/install.sh | sh -
   ```
2. Install dependencies:

  ```bash
  pnpm install
  ```
3. For development:

  ```bash
  pnpm run dev
  ```

4. For play:

   ```bash
   pnpm run play
   ```
